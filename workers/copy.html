کد کامل بات ورکر — کپی یک‌کلیکی

این همان workers/bot.js است، در یک فایل خودکفا: هیچ import، هیچ نصب و هیچ ترمینالی لازم نیست. فایل را کپی کنید و در ادیتور داشبورد Cloudflare بچسبانید.

در حال بارگذاری…
  1. Workers & Pages → Create → Workers (یا Worker موجود → Edit code).
  2. کل کد را بچسبانید → Deploy.
  3. Settings → Bindings → Add → KV namespace، نام متغیر KV.
  4. Settings → Variables and Secrets → Secret: TELEGRAM_BOT_TOKEN، ADMIN_IDS، ADMIN_SECRET، WEBHOOK_SECRET، GH_TOKEN → دوباره Deploy.
  5. Settings → Trigger Events → Cron: 0 * * * *.
  6. یک‌بار https://<worker>/setup?key=<ADMIN_SECRET> را باز کنید.
مرورگر اجازهٔ کپی خودکار نداد. متن انتخاب شده است: Ctrl+C (یا ⌘+C) را بزنید.
