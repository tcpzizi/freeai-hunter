بات تلگرام، فقط با داشبورد Cloudflare

هیچ دستوری در ترمینال لازم نیست؛ هر مرحله را می‌شود در مرورگر انجام داد. کل زمان: حدود ۱۰ دقیقه.

قبل از شروع
  • توکن بات از @BotFather (فرمت 123456:ABC…).
  • آیدی عددی خودتان (از @userinfobot).
  • یک حساب Cloudflare رایگان. پلن رایگان برای کار این بات کافی است.

۱) کد بات را کپی کنید

باز کردن فایل خام

فایل خودکفاست: هیچ import، wrangler یا فایل دیگری لازم ندارد. اگر دکمهٔ کپی کار نکرد، فایل را باز کنید و Copy raw file contents را بزنید.

۲) Worker را بسازید و کد را بچسبانید

  1. به Workers & Pages بروید.
  2. Create → Workers → Start with Hello World! → نامی مثل freeai-bot → Deploy.
  3. روی Worker تازه، Edit code را بزنید؛ کل محتوای ادیتور را پاک کنید و کد کپی‌شده را بچسبانید.
  4. Deploy بزنید. اگر خطای سینتکس گرفتید، یعنی کد کامل پیست نشده — دوباره از ابتدا کپی کنید.

۳) KV را وصل کنید (بدون این، هیچ کاربری ذخیره نمی‌شود)

  1. Storage & Databases → KV → Create a namespace با نام freeai-hunter-bot.
  2. برگردید به Worker → Settings → Bindings → Add → KV namespace.
  3. Variable name را دقیقاً KV بگذارید (حرف بزرگ) و همان namespace را انتخاب کنید → Save.
نام بایندینگ حساس است: کد دنبال env.KV می‌گردد. اگر kv یا MY_KV بگذارید، /diag مقدار kv_binding: "budget" یا خطا نشان می‌دهد.

۴) Secretها را اضافه کنید

Worker → Settings → Variables and Secrets → Add → نوع Secret (نه Text).

ناممقدارلازم؟
TELEGRAM_BOT_TOKENتوکن BotFatherبله
ADMIN_IDSآیدی عددی ادمین‌ها، با کاما: 111,222بله
WEBHOOK_SECRETیک رشتهٔ تصادفی؛ فقط A-Za-z0-9_-بله
ADMIN_SECRETیک رشتهٔ تصادفی دیگر؛ برای /setup و /diagتوصیه‌شده
GH_TOKENتوکن گیت‌هاب. اختیاری: نسخهٔ عمومی docs/offers.json بدون توکن هم خوانده می‌شودخیر
DATA_REPOپیش‌فرض tcpzizi/freeai-hunter؛ برای ریپوی دادهٔ خودتان عوض کنیدخیر
GEMINI_API_KEYتوضیح فارسی آفرها با Geminiخیر
GROQ_API_KEYجایگزین دومخیر

بعد از هر Save یک‌بار Deploy بزنید؛ Secretهای تازه تا Deploy بعدی به کد نمی‌رسند.

۵) زمان‌بندی ساعت

Worker → Settings → Trigger Events → Cron Triggers → Add → 0 * * * * (هر ساعت).

این گام لازم نیست اگر فقط با دکمهٔ /push خودتان ارسال می‌کنید.

۶) وبهوک و منوی دستورها

این آدرس را یک‌بار در مرورگر باز کنید (جای … آدرس Worker خودتان):

https://freeai-bot.<subdomain>.workers.dev/setup?key=<ADMIN_SECRET>

باید {"ok":true,…} ببینید. اگر false بود، فیلد description تلگرام را بخوانید (معمولاً توکن نامعتبر یا WEBHOOK_SECRET با کاراکتر غیرمجاز).

چون مقدار ADMIN_SECRET در URL است، بهتر است بعد از استفاده یک مقدار تازه بگذارید و دوباره Deploy کنید.

۷) بررسی سلامت (به همین ترتیب)

  1. /health → باید ok v8 بدهد.
  2. /diag?key=… → نسخه، تعداد آفر، کاربران، و بلوک source.
  3. /selftest?key=… → آیا این Worker می‌تواند داده را بخواند؟ دو مسیر را جدا نشان می‌دهد.
  4. در تلگرام به بات /start بدهید؛ برای بقیهٔ ادمین‌ها پیام تایید می‌رود.

اگر آفرها: 0 بود

سه علت رایج، سه راه‌حل:

در /diag چه می‌بینیدمعنیچه کنید
source.status: 401توکن معتبر نیست یا منقضی شدهتوکن تازه بسازید، یا GH_TOKEN را کامل حذف کنید و به مسیر عمومی تکیه کنید
source.status: 403توکن به آن ریپو دسترسی ندارد (ریپوی خصوصی)DATA_REPO را پاک کنید تا پیش‌فرض عمومی استفاده شود
source.status: 404فایل منتشر نشده یا مسیر/ریپو غلط استآخرین اجرای hunt یا recheck را ببینید که docs/offers.json را ساخته باشد
مسیر پیشنهادی: بدون هیچ توکنی کار کنید. Worker فایل docs/offers.json را از raw.githubusercontent.com می‌خواند؛ نه سقف rate limit دارد، نه به Secret نیاز دارد.

نکته‌های پلن رایگان

  • سقف KV: ۱٬۰۰۰ نوشتن در روز. با ۳۰ کاربر و ۲۴ اجرا حدود ۷۲۰ نوشتن — کمتر از سقف. اگر کاربر بیشتر شد، cron را هر ۲ ساعت بگذارید.
  • ۵۰ subrequest در هر اجرا و ۱٬۰۰۰ عملیات KV در هر اجرا سقف سختی است؛ کد این‌ها را می‌شمارد و به‌جای کرش کردن، کار را به اجرای بعد می‌سپارد.
  • KV نهایتاً سازگار است؛ تاریخچهٔ ارسال هر کاربر در رکورد خودش نگه داشته می‌شود تا آفر تکراری فرستاده نشود.
