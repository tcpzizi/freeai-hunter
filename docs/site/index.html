راهنماها

هر ابزار یا آفر می‌تواند یک راهنمای کوتاه داشته باشد: چطور کار می‌کند، سهم رایگان چقدر است، و برای چه کسی مناسب نیست. این بخش از sites.json خوانده می‌شود.

راه‌اندازی بات تلگرام روی Cloudflare Workers

هیچ نصبی لازم نیست. کد زیر را با یک کلیک کپی کنید و در داشبورد Cloudflare بچسبانید.

باز کردن فایل کد
  1. در Workers & Pages یک Worker بسازید (یا Worker موجود را Edit code کنید)، کل کد کپی‌شده را بچسبانید و Deploy بزنید.
  2. Settings → Bindings → Add → KV namespace؛ Variable name را دقیقاً KV بگذارید.
  3. Settings → Variables and Secrets و این‌ها را به‌عنوان Secret اضافه کنید: TELEGRAM_BOT_TOKEN، ADMIN_IDS، ADMIN_SECRET، WEBHOOK_SECRET، ADMIN_IDS با کاما برای چند ادمین. GH_TOKEN اختیاری است.
  4. Settings → Trigger Events → Cron Triggers و زمان‌بندی 0 * * * * را اضافه کنید.
  5. یک‌بار /setup?key=<ADMIN_SECRET> را در مرورگر باز کنید تا وبهوک و منوی دستورها ثبت شود.
  6. سلامت: /health باید ok v8 بدهد. اگر /diag گفت آفرها صفر است، /selftest?key=… علت و راه‌حل را می‌گوید.

راهنمای کامل با همان جزئیات در guide-worker.html و workers/README.md هست.

داده‌ها از docs/github-pages/offers.json و docs/github-pages/sites.json خوانده می‌شوند؛ ساعت‌ها به وقت Asia/Tehran هستند. این صفحه بدون وابستگی بیرونی کار می‌کند.
